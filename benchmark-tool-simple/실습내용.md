## 4. 성능 평가 실험 가이드
`script_run.sh`는 입력/출력 토큰 길이 1024/1024 고정, 동시 요청 수(concurrency) 1·4·8·16·32·64·128 조합으로 `benchmarks/benchmark_serving.py`를 반복 실행하며, NPU 모니터링 CSV와 결과 JSON을 `vllm-result/results-<결과_파일이름>_<포트번호>/<input>.<output>.<concurrency>/` 아래에 저장한다.
```
# bash ./script_run.sh [결과_파일이름 (예: performance_test)] [포트번호] 
# bash ./script_run.sh vllm 8000
./script_run.sh vllm 8000
```

## 5. 성능 평가 결과 확인하기
Ubuntu 서버에서 실행, 벤치마크 도구 디렉터리에서 다음 명령을 실행한다.

```

    --server.address 0.0.0.0 \
```

## 7. 정확한 지표 구성을 위해 확인할 내용
현재 대시보드는 결과 파일의 수치형 항목을 자동으로 시각화한다. 다만 TTFT, TPOT, Throughput 등을 올바른 단위로 표시하고 GPU·NPU를 정확히 비교하려면 JSON 내부 구조 확인이 필요하다.

다음 명령을 실행하면 된다.
```
cd ~/benchmark-tool-simple/vllm-result

python3 -m json.tool \
  results-vllm_8000/1024.1024.8/*.json | head -100
```

CSV 파일도 확인한다.
```
head -5 results-vllm_8000/1024.1024.8/*.csv
```

결과 JSON에는 다음과 같은 핵심 지표가 들어 있으며, 대시보드의 "비교할 측정 항목" 드롭다운에서 이 컬럼명으로 선택하면 된다.

| 지표 | JSON 필드 | 단위 | 의미 |
| --- | --- | --- | --- |
| TTFT (Time To First Token) | `mean_ttft_ms`, `median_ttft_ms`, `p99_ttft_ms` | ms | 첫 토큰이 나오기까지 걸린 시간 |
| TPOT (Time Per Output Token) | `mean_tpot_ms`, `median_tpot_ms`, `p99_tpot_ms` | ms | 토큰 1개를 생성하는 데 걸린 평균 시간 |
| ITL (Inter-Token Latency) | `mean_itl_ms`, `median_itl_ms`, `p99_itl_ms` | ms | 토큰 간 지연 시간 |
| E2E Latency | `mean_e2el_ms`, `median_e2el_ms`, `p99_e2el_ms` | ms | 요청 1건의 전체 응답 시간 |
| Throughput | `request_throughput`, `output_throughput`, `total_token_throughput` | req/s, tokens/s | 처리량 (요청/출력 토큰/전체 토큰 기준) |
| Power | `mean_power_consumption`, `median_power_consumption`, `p99_power_consumption` | W | NPU 전력 소비량 (`--enable-device-monitor npu`로 수집) |

GPU 결과와 비교할 때는 같은 필드명(예: `mean_ttft_ms`, `output_throughput`)을 기준으로 맞춰야 단위 차이로 인한 왜곡 없이 비교할 수 있다. NPU 모니터링 CSV(`npu-*.csv`)는 전력·온도·유틸리제이션 등 장치 상태를 시간순으로 기록하므로, JSON의 요약 지표와 별도로 구간별 변화를 확인할 때 활용한다.

## 8. 실습 정리
1. `furiosa-smi`로 RNGD 장치 상태(개수, utilization, 전력, 온도)를 모니터링한다.
2. `furiosa-llm serve`로 Qwen3-8B-FP8 모델을 서빙하고 `curl`로 정상 응답을 확인한다.
3. `script_run.sh vllm 8000`을 실행해 concurrency 1~128 구간의 벤치마크 결과(JSON+CSV)를 `vllm-result/`에 수집한다.
4. `benchmark_dashboard.py`를 Streamlit으로 띄워 결과 디렉터리를 자동 시각화한다.
5. SSH 포트 포워딩으로 안전하게 대시보드(`:8501`)에 접속한다.
6. 결과 JSON/CSV의 실제 필드명(TTFT·TPOT·ITL·Throughput·Power)을 확인해, 대시보드에서 올바른 단위로 비교 항목을 선택한다.
7. 동일 필드명 기준으로 GPU/NPU 결과를 나란히 비교해 성능 차이를 분석한다.
